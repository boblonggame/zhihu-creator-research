# 创作者内容分析维度

## 证据等级

| 标签 | 使用条件 | 表达要求 |
|---|---|---|
| 直接表述 | 作者明确赞成、反对、定义或判断 | 附标题、日期、URL，可用必要短引 |
| 跨内容归纳 | 至少两篇内容共同支持但不是作者原话 | 明示“归纳”，列出多条来源和可能反例 |
| 证据不足 | 单篇、摘要、来源缺失、样本短或相互冲突 | 保留问题，不升级为稳定结论 |

“核心观点”“长期主线”原则上需要至少三篇独立内容，且覆盖不止一个时间点。达不到时使用“样本期内反复出现”或“单篇提及”。

## 维度一：语料范围与阶段

- 内容类型、数量、时间跨度和分页完整性；
- 发布频率与明显空窗；
- 内容主题随时间的新增、弱化、持续或反转；
- 失败项和可能造成的偏差。

不要从没有内容的时间段推断作者沉默的原因。

## 维度二：主题与知识框架

- 高频但有语义支撑的主题；
- 作者反复使用的概念、因果链、判断标准和方法；
- 主题之间的上下游关系；
- 不同主题是否共享同一套分析框架。

关键词频次是候选线索，不是结论。检查同义词、否定句、引用他人和反讽语境。

## 维度三：观点与价值判断

- 明确支持或反对什么；
- 判断“好 / 坏”“重要 / 次要”的标准；
- 观点成立的前提、时间和对象；
- 是否出现条件变化后的修正。

观点表格建议字段：结论、标签、适用范围、支持来源、反例、置信度。

## 维度四：论证方式

- 使用数据、案例、类比、权威引用还是个人经验；
- 是否主动处理反例和不确定性；
- 结论和证据之间是否存在跳跃；
- 语气和修辞只能描述文本表现，不应升级为人格诊断。

## 维度五：外部事实与利益边界

- 作者的事实主张是否尚未独立核验；
- 是否存在广告、持仓、职业或合作关系披露；
- 点赞、评论和收藏只代表平台互动，不代表正确性；
- 对金融、医疗、法律等高风险主题，必须把观点归纳与专业事实核验分开。

## 反例检查

每个高置信结论至少检查一次：

1. 是否有时间更晚的相反表述；
2. 是否只是引用或转述他人；
3. 是否只针对特殊对象或前提；
4. 是否因采集不完整而遗漏相反内容；
5. 是否把高频主题误当成明确立场。
